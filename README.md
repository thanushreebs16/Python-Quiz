# Python Quiz

## Description
Python Quiz is a console-based quiz application developed using Python. The program presents multiple-choice questions in random order, accepts user input, checks answers, and calculates the final score.

## Features
- 10 multiple-choice Python questions
- Questions appear in random order
- Automatic score calculation
- Instant feedback for correct and incorrect answers
- Displays the correct answer when the user selects the wrong option
- User-friendly console interface

## Technologies Used
- Python 3
- Git
- GitHub

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Run the following command:

```bash
python quiz.py
```
